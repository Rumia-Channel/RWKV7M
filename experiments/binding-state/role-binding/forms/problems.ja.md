# 問題用紙の例（すべてオリジナル）

各形式の先頭のデータseed・家族0・世界0。最初の2枚は学習用、最後は本番の中テスト。モデルには公開JSONのトークン列と照合表を渡す。

## 基礎

次の記録を読んで、二つの問いに物の名前で答えなさい。
エヴィ が フェン に 石 を 渡した 。
ベクス に 貝 を エヴィ が 渡した 。
エヴィ に カップ を フェン が 渡した 。
エヴィ に 葉 を ベクス が 渡した 。
エヴィ が フェン に 何 を 渡した ？

## 入試風の応用

入試演習：物流センターの配布記録

物流センターでは、八種類の品物を担当者どうしで配っています。以下は整理前の記録も含む搬送台帳です。
同じ「渡した人→受け取った人」の記録が複数あるときは、番号がいちばん大きい「渡した」の品物を採用します。後の有効な記録は前の記録の訂正です。
「渡そうと考えた」は予定だけで、受け渡しや訂正として数えません。

【照会の手順：各問とも記録をちょうど3回照会】
まず、その問の出発の質問について、上の規則で品物を一つ求めます。
最後の照会でなければ、いま求めた品物を下の8行の索引で探し、その行の質問を次の照会に使います。これを繰り返し、3回目に得た品物だけを解答欄に書きます。
問1と問2は別々に出発します。索引の行の並び順には意味がありません。

## 中テスト

単元の中テスト：部活動の備品登録

部活動では、展示用の八種類の備品を生徒どうしで渡しています。次の連絡メモは、部員が当番へ伝えた内容を記録順に並べたものです。
同じ「渡した人→受け取った人」の記録が複数あるときは、番号がいちばん大きい「渡した」の品物を採用します。後の有効な記録は前の記録の訂正です。
